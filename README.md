# homebrew-moomux-mac

Homebrew cask tap for [Moomux.app](https://github.com/afitzgerald/moomux-mac), the native macOS
front end for [moomux](https://github.com/erickgnclvs/moomux).

```sh
brew install --cask afitzgerald/moomux-mac/moomux-mac
```

Casks are published automatically by moomux-mac's release workflow — don't edit `Casks/` by hand.
